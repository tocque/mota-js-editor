# Left1 面板 - 素材追加面板

## 面板标识
- **DOM ID**: `left1`
- **模式名称**: `appendpic`
- **对应模块**: `editor_materialpanel.js` (素材追加相关函数)

## 功能概述

素材追加面板用于向游戏添加新的图像素材。支持从本地导入图片文件，在画布上选择需要的图块区域，然后追加到对应的素材分类中。支持自动注册ID、色相调整、快速追加等高级功能。

## UI组件结构

### 1. 顶部操作区

```
[导入文件到画板] [素材分类▼] [追加] [快速追加] ☑自动注册
```

**组件**:
- `#selectFileBtn` (按钮): 打开本地文件选择对话框
- `#selectAppend` (下拉框): 选择目标素材分类
  - `terrains` - 地形素材
  - `animates` - 动画素材
  - `enemys` - 怪物行走图（32x32）
  - `enemy48` - 怪物行走图（48x48）
  - `items` - 道具素材
  - `npcs` - NPC行走图（32x32）
  - `npc48` - NPC行走图（48x48）
- `#appendConfirm` (按钮): 追加选中的图块到素材库
- `#quickAppendConfirm` (按钮): 快速追加（4x4道具素材一次追加16个）
- `#appendRegister` (复选框): 是否自动注册到对应的配置文件

### 2. 色相调整滑块

```
色相: [========|========] (0-12)
```

**组件**:
- `#changeColorInput` (range滑块): 调整导入图片的色相值
- 范围: 0-12（0为原色，其他值对应不同色相偏移）

### 3. 画板区域 (`#appendPicCanvas`)

```
┌────────────────────────────┐
│  背景层 (灰白格子背景)       │
│  ┌──────────────────────┐  │
│  │  源图片层             │  │
│  │  (导入的原图)         │  │
│  └──────────────────────┘  │
│  点击响应层                 │
│  [选择框] ← 1 2 3 4         │
└────────────────────────────┘
```

**Canvas层叠** (4层):
1. **背景层** (`canvas[0]`): 绘制灰白相间的透明背景
2. **源图片层** (`canvas[1]` / `#appendSource`): 显示导入的原始图片
3. **点击层** (`canvas[2]` / `#appendPicClick`): 处理鼠标点击选择
4. **临时层** (`canvas[3]` / `#appendSprite`): 隐藏层，用于生成裁剪后的sprite

**选择框** (`#appendPicSelection`):
- 4个编号区域（1-4），用于标识选择的图块位置
- 显示当前选中的32x32或48x48区域

## 核心功能

### 1. 导入图片文件

**触发**: 点击 `#selectFileBtn`

**流程**:
```
选择本地图片 → 读取文件 → 绘制到源图片层 → 等待用户选择区域
```

**支持格式**: PNG, JPG, GIF等浏览器支持的图片格式

**实现位置**: `editor_materialpanel.js` 相关事件处理

### 2. 拖拽直接追加 (V2.7.1+)

**功能**: 直接将图片文件拖拽到右侧对应的素材区，自动完成追加和注册

**支持**:
- 单个图块拖拽
- 4x4道具素材拖拽（自动追加16个）

### 3. 选择图块区域

**操作方式**:
- 在画板上点击选择32x32（或48x48）的图块区域
- 选择框会高亮显示当前选中区域
- 可多次点击更改选择

**选择逻辑**:
- 根据 `#selectAppend` 的分类自动判断图块尺寸
- `enemy48` / `npc48` 使用48x48尺寸
- 其他分类使用32x32尺寸

### 4. 追加到素材库

**普通追加** (`#appendConfirm`):
- 将选中的单个图块追加到目标分类
- 文件名自动生成（如 `item_1.png`, `enemy_2.png`）
- 保存到 `project/images/` 对应子目录

**快速追加** (`#quickAppendConfirm`):
- 专为4x4道具素材设计
- 一次性追加16个图块
- 适用于批量导入道具库

**追加后操作**:
- 图片保存到对应目录
- 如勾选"自动注册"，同时更新配置文件：
  - `icons.js` - 添加图标ID映射
  - `items.js` / `enemys.js` - 添加默认属性配置

### 5. 色相调整

**功能**: 在追加前调整图片的色相值

**应用场景**:
- 制作同一怪物的不同颜色变体
- 调整素材整体色调以匹配游戏风格

**实现**: 通过Canvas滤镜实时调整显示

## 数据流

```
本地图片文件
       ↓
导入到画板 (appendSource canvas)
       ↓
用户选择区域
       ↓
(可选) 调整色相
       ↓
点击追加按钮
       ↓
裁剪图块 → 生成新文件名
       ↓
保存到 project/images/{category}/
       ↓
(如勾选) 自动注册到 icons.js
       ↓
(如勾选) 添加默认属性到 items.js/enemys.js
       ↓
刷新右侧素材库显示
```

## 使用场景

1. **添加新怪物**: 导入怪物行走图 → 选择朝下帧 → 追加到enemys → 自动注册ID
2. **批量道具**: 导入4x4道具图 → 快速追加 → 一次性生成16个道具素材
3. **颜色变体**: 导入基础怪物图 → 调整色相 → 追加为不同颜色的同类怪物
4. **自定义地形**: 导入地形图 → 逐个追加不同地形块 → 在地图中使用

## 注意事项

1. **文件名唯一性**: 追加时会检查是否已存在同名文件，避免覆盖
2. **尺寸要求**: 
   - 32x32素材：确保选择区域对齐32像素网格
   - 48x48素材：确保选择区域对齐48像素网格
3. **自动注册**: 
   - 勾选后会自动分配ID（如 `enemy_new_1`, `item_new_2`）
   - 需要后续在属性面板中修改详细配置
4. **快速追加**: 仅适用于标准4x4排列的道具素材，其他类型请使用普通追加
5. **色相调整**: 调整后的图片会永久保存，原图不受影响

## 快捷操作

- **拖拽追加**: 直接拖图片到右侧素材区（最快速）
- **批量导入**: 使用外部工具拼接多个素材到一张大图，然后逐个选择追加
- **色相快速切换**: 使用键盘左右方向键快速调整色相滑块
