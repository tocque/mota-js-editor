# Left 面板 - 地图编辑面板

## 面板标识
- **DOM ID**: `left`
- **模式名称**: `map`
- **对应模块**: `editor_mappanel.js` (1190行)

## 功能概述

地图编辑面板是编辑器的默认面板，用于直接编辑地图数据的文本表示形式。提供了二维数组文本编辑器，可以批量导入/导出地图数据，以及创建、删除楼层等操作。

## UI组件结构

### 1. 地图数组编辑器 (`#arrEditor`)

```
┌─────────────────────────────┐
│ 列标记 (arrColMark)          │
├──┬──────────────────────────┤
│行│  #mapEditArea           │
│标│  ┌──────────────────┐   │
│记│  │ #pout (textarea)  │   │
│  │  │ 地图数据文本框     │   │
│  │  └──────────────────┘   │
└──┴──────────────────────────┘
```

**组件说明**:
- `#arrColMark`: 列标记表格，显示列号
- `#arrRowMark`: 行标记表格，显示行号
- `#pout`: 大型文本框，显示和编辑地图的二维数组数据

**数据格式示例**:
```javascript
[
  [0, 0, 1, 1, 0],
  [0, 201, 0, 0, 0],
  [1, 1, 1, 1, 1]
]
```

### 2. 新建单个地图 (`#editTip`)

**组件**:
- `#newMap` (按钮): 触发创建新楼层
- `#newFileName` (输入框): 新楼层ID，如 `MT1`
- `#newMapWidth` (输入框): 地图宽度
- `#newMapHeight` (输入框): 地图高度
- `#newMapStatus` (复选框): 是否保留楼层属性

**功能**: 创建一个全新的空白楼层文件

### 3. 地图操作按钮 (`#editBtns`)

- `#exportMap`: 将当前楼层地图数据导出并复制到剪贴板
- `#importMap`: 从 `#pout` 文本框导入地图数据到当前楼层
- `#clearMapButton`: 清空当前楼层的所有图块（填充为0）
- `#deleteMap`: 删除当前楼层文件

### 4. 批量创建地图 (`#newMaps` / `#newFloors`)

**触发按钮**: `#newMaps` - "批量创建空白地图 ↓"

**展开区域** (`#newFloors`):
- `#newFloorIds`: 楼层ID格式，支持模板变量 `${i}`，如 `MT${i}`
- `#newFloorTitles`: 地图中文名格式，如 `主塔 ${i} 层`
- `#newFloorNames`: 状态栏名称格式，如 `${i}`
- `#newMapsWidth`: 批量地图宽度
- `#newMapsHeight`: 批量地图高度
- `#newMapsStatus`: 是否保留楼层属性
- `#newMapsFrom`: 起始编号 `i`
- `#newMapsTo`: 结束编号 `i`
- `#createNewMaps`: 确认创建按钮

**功能**: 批量创建多个楼层，如一次性创建 MT1~MT50

## 核心功能

### 1. 地图数据文本编辑

**实现位置**: `editor_mappanel.js`

**功能描述**:
- 显示当前楼层的三层地图数据（bgmap, map, fgmap）的文本表示
- 支持手动编辑数组数据
- 行列标记辅助定位

**相关函数**:
```javascript
// 填充文本框的地图数据
editor.uifunctions.showMapInTextarea()
```

### 2. 导入/导出地图

**导出功能** (`#exportMap`):
- 将当前楼层的地图数据格式化为 JSON 数组
- 自动复制到剪贴板
- 可用于备份或跨楼层复制

**导入功能** (`#importMap`):
- 从 `#pout` 文本框读取 JSON 数组
- 解析并更新当前楼层的地图数据
- 自动保存到 `project/floors/` 目录

**数据结构**:
```javascript
{
  "bgmap": [[...], [...]], // 背景层
  "map": [[...], [...]],   // 事件层
  "fgmap": [[...], [...]]  // 前景层
}
```

### 3. 创建新楼层

**单个创建**:
- 指定楼层ID、宽度、高度
- 可选择是否复制当前楼层属性到新楼层
- 创建文件: `project/floors/{floorId}.js`

**批量创建**:
- 使用模板变量 `${i}` 生成多个楼层
- 同时更新 `data.js` 中的 `main.floorIds` 数组
- 自动生成默认楼层属性

### 4. 清除和删除地图

**清除地图** (`#clearMapButton`):
- 将三层地图数据全部填充为 `0`
- 保留楼层文件和属性

**删除地图** (`#deleteMap`):
- 删除整个楼层文件
- 从 `main.floorIds` 中移除
- 不可恢复操作

## 数据流

```
用户编辑 #pout 文本框
       ↓
点击"从框中导入地图"
       ↓
editor.file.importMap()
       ↓
解析 JSON 数据
       ↓
更新 core.status.maps[floorId]
       ↓
保存到 project/floors/{floorId}.js
       ↓
刷新画布显示
```

## 使用场景

1. **快速批量编辑**: 直接修改数组数据，比可视化点击更快
2. **地图复制**: 导出某楼层数据，导入到另一楼层
3. **批量初始化**: 一次性创建多层楼层框架
4. **数据调试**: 查看和修改精确的数组索引值
5. **模板应用**: 从外部工具生成的数组数据导入

## 注意事项

1. **数据格式要求**: 必须是有效的 JSON 二维数组格式
2. **尺寸一致性**: 导入的地图宽高应与楼层设置一致
3. **ID有效性**: 数组中的数字必须是已注册的图块ID或事件ID
4. **删除不可逆**: 删除楼层操作无法撤销
5. **批量创建限制**: 楼层ID不能与已有楼层重复

## 快捷操作

- 直接在文本框中编辑数组进行批量修改
- 使用 Ctrl+A 全选数组数据
- 配合外部编辑器生成规则地图（如对称、重复图案）
